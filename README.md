## ⚙️ Instalação

```bash
# Clone o repositório
git clone https://gitlab.com/ReneGustavo/undefined.git

# Entre na pasta
cd undefined

# Instale as dependências
yarn install
```

## 🔧 Configuração

Copie o arquivo *.env.example*, renomeie para *.env* e preencha com os valores adequados.

## ▶️ Executando o projeto

### Ambiente de desenvolvimento

```bash
yarn dev
```

### Build

```bash
yarn build
```

### Ambiente de produção

```bash
yarn start
```
